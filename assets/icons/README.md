# Dailoop Symbols

Four original vector outlines (home, bell, folder and flame) in a 1,472-byte local font. Same MIT license as Dailoop. They use the app palette and do not depend on the device's emoji artwork or a remote font service.

Rebuild with `python scripts/generate-ui-icons.py`; the script documents its tooling-only FontTools installation under the ignored output directory. Stable timestamps make the generated font reproducible. No extra JavaScript or native rendering dependency is required by the app.
