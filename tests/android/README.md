# Flujos Android históricos

Los YAML de esta carpeta y sus subcarpetas documentan validaciones de 0.1.0, 0.1.5 y 0.1.6. Se conservan como evidencia; sus nombres de pestañas, coordenadas y recorridos no certifican la interfaz actual 0.5.0. Historial ahora está dentro de Estadísticas, e Inicio se llama Registro.

No ejecutarlos de forma indiscriminada ni contra emulator-5580 o el teléfono personal. Una validación nativa posterior requiere un destino propio identificado y flujos actualizados para la candidata. Las pruebas Web actuales de producción están en playwright.release.config.ts y usan bases de navegador aisladas.
