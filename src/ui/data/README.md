# Emoji catalog

Local Unicode Emoji 17.0 catalog with CLDR 48 Spanish annotations, including skin tones, gender sequences, families and flags. Rendered with the device's emoji glyphs; no image/font downloads or runtime network requests. New glyph availability depends on the device.

Generated with `node scripts/build-emoji-catalog.mjs`. Unicode data license: [UNICODE-LICENSE.txt](../../../licenses/UNICODE-LICENSE.txt). Sources and SHA-256:
